## 🏗️ Technical Showcase

### **[SharedSocial-KMP](https://github.com/massimilianoPugliatti/SharedSocial-KMP)**
Repository pubblico che applica standard architetturali enterprise a **Kotlin Multiplatform**.
* **Clean Architecture & MVI:** separazione netta dei layer e gestione atomica dello stato della UI.
* **Camera nativa:** implementazioni native Android (CameraX) e iOS (AVFoundation) per l'acquisizione di foto e video.
* **Security:** storage crittografato tramite **Google Tink** e **Keychain**.
* **CI/CD:** pipeline GitHub Actions con test e build di Android e iOS.

### **[NewsApp](https://github.com/massimilianoPugliatti/NewsApp)**
App Android nativa per consultare le ultime notizie tramite NewsAPI, costruita come esempio di architettura moderna **offline-first**.
* **Clean Architecture & MVVM:** layer presentation, domain e data separati e organizzati per feature, con use case dedicati.
* **Offline-first:** Room come *single source of truth*; la UI osserva i Flow del database e gli articoli restano consultabili anche senza connessione.
* **UI reattiva:** Jetpack Compose, StateFlow ottenuto combinando più sorgenti, eventi one-shot gestiti tramite Channel.
* **Stack:** Retrofit e OkHttp, Room, Hilt, Coil, Kotlin Coroutines e Flow.
* **Testing:** unit test su ViewModel, repository e use case con **MockK** e **Turbine**.
